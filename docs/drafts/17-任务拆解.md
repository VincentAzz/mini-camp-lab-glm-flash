## 1. 阶段总览

按用户指定的推进顺序分为 **8 个阶段、48 个任务**：

```
P1 脚手架(7) → P2 公共系统(10) → P3 场景×4(5) → P4 车型×5(6) → P5 时间/天气(6) → P6 UI(6) → P7 动效打磨(5) → P8 验收复盘(3)
```

| 阶段 | 目标 | 产出可验收物 | 关键原文依据 |
|---|---|---|---|
| P1 脚手架 | 工程地基：依赖安装（需审批）+ 核心基建 + 渲染冒烟 | 打开即渲染空底座的工程 | 八.1/八.5、九.5、架构 §2 |
| P2 公共系统 | 八.4 L123 点名的 6 项公共系统 + 支撑件 + Director 编排 | 每套系统可独立挂到测试页面验证 | 八.4、七.5、四-5、五-3/5-5 |
| P3 场景×4 | 逐场景独立交付（地形/道具/动效/色彩/光照钩子） | 单场景可独立装配验收 | 2.1–2.5、7.1–7.4 |
| P4 车型×5 | 逐车型独立交付（外部/展开/内饰/内饰灯） | 单车型可在任意场景落位验收 | 3.1–3.6 |
| P5 时间/天气 | 四档时间 + 五档天气正式数据与端到端过渡 | 时间/天气全维切换可验收 | 四节、五节 |
| P6 UI | 六.1–六.5 全部 UI 功能 + 切换端到端 | 完整可巡游的控制界面 | 六节、一.4 |

| P8 验收复盘 | 400 组合核验 + 逐节最终自查 + 收尾 | 交付 | 十一、九.3 |

## 3. 阶段 P2 · 公共系统（T08–T17）

> 每套系统以「可独立验收」交付：各系统在 dev 测试页可单独挂载演示，验收后再进 Director 编排（T17）。

- **对照**：七.5 L116「灯光呼吸统一节奏」、时间天气章 §4.1（B4）、架构 §4-1。

- **对照**：七.5 L116（布料统一受风力、风随天气）、五-2 L94（风力略增）、五-3 L95（积水下凹）、四-2 L84（投影清晰）、架构 §4-2、D3、时间天气章 §4.2、场景章 §8.3-P2。

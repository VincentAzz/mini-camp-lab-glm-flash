## 1. 四场景共通实现约定

### 1.1 统一正方形底座（原文一·3、2.0c）——BaseAssembler 统一生成，场景只给样式

底座**不归场景建模**（架构 §3.2 注记）。四场景共用同一 BaseAssembler 参数骨架，形式完全统一，仅 `palette.baseStyle` 差异：

**统一骨架（BaseAssembler 内定值）**：

| 项 | 值 | 说明 |
|---|---|---|
| 底边长 B | 20u × 20u | 全场景一致，"完整的正方形底座"字面落实 |
| 台面高度 | y = 0（顶面），底座厚 1.5u | 场景地形只能在其上做下沉层/抬升层 |
| 边缘处理 | 四周 45° 倒角台缘 + 底缘内收 0.15u 的"模型剖面"阶梯 | 微缩陈列盒的"被切开的模型"观感，全场景一致 |
| 底盘 | 底面 y=−1.5 处 19.2×19.2 深灰托板 | 陈列感收口，全场景一致 |

**`BaseStyleSpec` 字段（架构留白，本章提案，待架构章确认）**：

```ts
interface BaseStyleSpec {
  topTheme: string;        // 台面主题材质 id（_geom/parts/baseTop 工厂取用）
  edgeMatId: string;       // 倒角台缘材质 id
  rimDecal?: string;       // 台缘装饰贴图 id（如警示斜纹）
  skirtLayers: number;     // 下沉层数量声明（供 BaseAssembler 预留 z-fighting 间距）
  silhouette?: {           // 后缘剪影板（D1）：低细节远景板
    height: number; kind: 'mountains' | 'bridge' | 'skyline' | 'coast';
  };
}
```

**四场景 baseStyle 差异表（形式统一、材质与边缘不同——原文一·3 后半句）**：

| 场景 | topTheme | 台缘 edgeMatId | rimDecal | skirtLayers | silhouette |
|---|---|---|---|---|---|
| 海崖 | `lawn`（草地噪点+浅草色斑 Canvas） | 岩层剖面（三条沉积层带） | 无 | 1（海面下沉 −2.6） | `coast`（远海已由下沉层承担） |
| 松林 | `gravel`（碎石地：灰绿底+随机砾石点 Canvas） | 根系土层（土色+根须凸点） | 无 | 1（溪谷下沉 −1.6） | `mountains`（层叠山脊两层板） |
| 避难所 | `crackedConcrete`（裂纹混凝土+沙地补丁 Canvas） | 混凝土毛面 | 黄黑警示斜纹（四角） | 0 | `bridge`（断裂高架桥）+ `skyline`（城市剪影） |
| 服务区 | `asphaltLot`（沥青噪点+划线贴图区） | 路缘石（浅灰+断面深灰） | 无 | 1（公路下沉 −0.12） | 无（服务区无远景元素，剪影板省略） |

> 台缘材质的"剖面感"统一实现：edgeMatId 对应一张 Canvas 竖条纹/层理贴图，UV 沿台缘四边环铺——四个场景用同一 UV 方案换贴图，保证"形式统一"。

### 1.2 分层底座与远景收纳（决策 D1 落地）

- **下沉层**：场景在 `buildTerrain` 内声明下沉区域（海面/溪谷/公路），下沉层底部由 BaseAssembler 的 skirtLayers 预留承载；下沉区边缘做 0.25u 宽的过渡斜坡（倒角）避免硬切。
- **后缘剪影板**：贴在底座后缘（z=−10）内侧、面向观众的低细节平面（Canvas alpha 剪影），随全局光照同色调（读 `SceneLightState.global` 的天空端点色插值）；浓雾时透明度按 `fogDensity` 提升（五-4"远景逐层雾化"的落点——剪影板分层越多雾化层次越明显）。
- **任何远景元素不允许越出 20×20 底座**（帆船、山脊、高架桥、城市剪影全部收在内），保证任何相机角度不穿帮（D1）。

### 1.5 公共系统句柄接入约定（原文 2.5 × 七-5 × 架构 D3）

四场景与公共系统的**唯一交汇面是四类句柄**（架构 systems/handles.ts）。每场景交出量预估：

| 场景 | cloths | lamps | emitters | weatherSurfaces |
|---|---|---|---|---|
| 海崖 | 2（天幕、纸巾） | 3（串灯、营地灯、灯塔） | 1（烧烤炉炊烟） | 4（草坪 ground、栈道 roofTop、天幕 clothTop、护栏 roofTop） |
| 松林 | 4（吊床、毛巾×3） | 1（篝火光效挂点） | 3（篝火火星、树冠滴水×2） | 5（碎石地 ground、平台 roofTop、树冠 roofTop、桥面 roofTop、毛巾 clothTop） |
| 避难所 | 3（工装×3） | 4（探照灯、警示红灯、天线指示灯、净水荧光） | 4（发电机蒸汽、火堆火星、光柱微尘、檐口滴水） | 5（硬化地 ground、集装箱顶/掩体顶/铁皮墙 roofTop、沙袋堆 roofTop） |
| 服务区 | 1（小旗） | 5（便利店灯箱、招牌闪块、售货机灯带、加油棚灯、出口牌微光） | 2（雨棚滴水×2） | 6（停车区 ground、公路 ground、划线 linePaint、雨棚顶/店顶/长椅顶 roofTop） |

- **布料一律 `ClothHandle` → WindSystem**（七-5"布料类统一受风力参数控制"；架构 D3 归属裁定）：场景**不写任何布料模拟代码**，只给 `swayAxes/stiffness`。
- **粒子一律 `EmitterSpec` → ParticleSystem**：kind 从枚举 `steam/spark/mist/dust/drip/…` 取，场景给 area/rate。
- **灯点一律 `LampHandle` → LightBreathSystem**：mode 取 `steady/breath/blink/rotate`，呼吸相位由 RhythmClock 统一（七-5"灯光呼吸统一节奏"），本章参数表给出的 period/amp 即注册参数。
- **天气作用面一律 `WeatherSurface`**：`ground`=湿润/薄雪，`roofTop`=顶部积雪，`clothTop`=布面下凹+积雪，`linePaint`=划线 lineFade（五-5 服务区特例）。

### 1.6 不要人物（原文一·6，硬红线）

- 部件库铁律（架构 §2 部件库注记）：`geom/parts/` 全库禁止任何人体/人形几何。四场景逐项自查：
  - 海崖：无人物；"刚刚出海的帆船"为空船自动航行（动效载体），船上无人。
  - 松林：松鼠为原文 7.2 点名的动物；鸟屋是道具，不出现鸟的常态模型（海鸟仅海崖动效）。
  - 避难所：**汽车残骸内严禁任何乘员/骸骨类几何**，残骸=空车体+覆尘（干净治愈系末世，一·5）；警示牌不用骷髅图形（§8 拍板）。
  - 服务区：便利店/食堂只有"窗内暖光+货架剪影 alpha 贴图"表达生活气息，**不建任何店内人形剪影**；售货机、加油站均无人。
- 生命的温度由道具与动效承载（一·6 后半句）：早餐餐具、晾晒衣物、送货小车、篝火、蒸汽等"刚有人活动过"的痕迹感，是四场景共通的叙事手段。

### 1.7 三渲二材质参数约定（原文一·2、八·2）

全部材质经 `ToonMaterialFactory` 创建（架构 render/toonMaterial.ts），本章材质写法统一为：`色值 + 色阶数 + 描边开关`。

| 材质类 | ramp 色阶 | 描边 | 备注 |
|---|---|---|---|
| 建筑大面（店体/掩体/集装箱/悬崖） | 3 阶 | 开（宽 2.2px） | 大轮廓清晰 |
| 植被（树冠/灌木/海草） | 2 阶 | 开（宽 1.6px，树冠）/关（草叶 alpha 面） | alpha 面关描边防白边 |
| 细碎小物（灯泡/餐具/管线/台阶） | 2 阶 | 关 | 控 draw call（架构 §7-4） |
| 自发光（灯箱/灯带/火焰/波光/光柱） | MeshBasicMaterial + additive/半透 | 关 | 走 LampHandle/动效亮度 |
| 水面 | 2 阶 + 波光 additive 层 | 开（岸线） | `waterSurface` 部件内置 |
| 玻璃（窗/售货机窗） | 半透 toon（α 0.25–0.4）+ 内衬 emissive 面 | 开 | "可透视"由内衬面而非真穿透 |

### 8.4 自认风险

1. **崖体 Extrude 轮廓的描边壳**：拉伸体侧壁倒角处反壳描边易出现破面，需 OutlineSystem 支持"仅顶缘描边"或对崖体改用顶缘 Tube 描边（留实现期验证点）。
2. **clothMicro 的极小布料（0.28²）在风力大时穿模**：纸巾/小旗与所在地面/杆件间距小，需 WindSystem 支持每 handle 的 maxAmp 钳制（列入 P2 附带期望）。
3. **车流光轨 additive sprite 在浅色雪地上会过曝**：服务区降雪+夜间组合需对光轨 α 再乘 0.7（实现期在 §5.3-① 加雪面修正分支）。
4. **城市剪影与浓雾的层次**：两层剪影板+雾板的排序（renderOrder）需实现期调，可能出现雾板遮灯箱的错帧。
5. **参数表为纸面定值**：§x.3/§x.5 的全部数值未经运行验证，属于 Q4 意义上的"可复盘初值"，TASKS.md 勾验时以实机观感为准整体微调。

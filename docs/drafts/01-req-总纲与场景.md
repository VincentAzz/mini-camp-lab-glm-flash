## 一、逐条要点

### 第一节 整体形式与美术总纲（原文一·1 ～ 一·6）

- **1.1** 形式：网页端交互式三维小玩具（微缩模型陈列盒），第三视角环绕观察，可自由拖拽旋转、滚轮缩放观看，触屏同样支持。
- **1.2** 画面风格为三渲二：高精细建模、三渲二卡通渲染、清晰的轮廓线（描边明确）、细腻但简洁的材质层次、材质表现干净、色彩柔和但富有层次感，强调浓厚的日式二次元动画氛围与二次元夏日旅途场景感。
- **1.3** 每个场景的地面都为一个**完整的正方形底座**，所有元素都搭建在这个底座上，构图紧凑、层次清晰，整体呈现小巧、精致、可收藏的模型感；不同场景只更换底座的材质与边缘处理，但"微缩底座"的形式必须统一。
- **1.4** 配一套轻量 UI 控制界面用于切换场景 / 车型 / 时间 / 天气（细节见第六节，邻域）；除这套 UI 外画面本身**不出现其他 HUD 类杂乱元素**，模型本体保持纯净的陈列感，并提供"隐藏 UI"入口回到纯观赏模式。
- **1.5** 整体气质：安静、治愈、带一点旅途黄昏的辽阔孤独感但依然温暖，像一幕幕被定格下来的日本动画场景模型；该气质**适用于所有场景，包括末世场景**——末世也要画得干净、有秩序感与生活气息，**不追求写实血腥或恐怖**。
- **1.6** **不要人物**；生命的温度全部由场景道具、车内陈设与动效来承载。

### 第二节 导言（原文二，2.1 之前的总述）

- **2.0a** 场景系统首发 **4 个场景**，架构上可继续扩展。
- **2.0b** 场景与车型、时间、天气**完全解耦**：任何车辆可以停在任何一个场景的**中央营位**，任何一个场景都可以在任何时间与天气下观看。
- **2.0c** 每个场景的构成公式 = 一块正方形底座 + 环境元素 + 场景专属动效 + 场景专属色彩基调（色彩基调再被时间与天气系统调制）。

### 2.1 海崖营地（默认场景）

- **2.1.1** 地形与构图：悬崖草坪上的**临崖营位**，停放的车辆位于底座**视觉中心**；营地不需要太大，但必须有明确的"**临崖观海**"构图，像日本动画里常见的夏末旅行一幕。
- **2.1.2** 营地元素共 **15 组**，全部要实现：①遮阳天幕与折叠桌椅、②串灯、③烧烤炉、④野餐垫、⑤小营地灯、⑥防水地垫、⑦连接水电桩的管线、⑧营位旁的小型折叠自行车、⑨木栈道、⑩崖边护栏、⑪观景长椅、⑫路牌、⑬海草与礁石、⑭通往小海湾的石阶、⑮远处海面上的小型帆船与防波堤灯塔。
- **2.1.3** 色彩基调：日落金橙与海面蓝紫渐变的层次感、海面粼粼波光与天边晚霞渐变、（黄昏时）暖色车内灯光与冷色暮色海景的鲜明冷暖对比，营造非常典型的日式动画公路旅行氛围。

### 2.2 山间松林营地

- **2.2.1** 地形与构图：一片被高大层叠松林环抱的**林间空地碎石营位**，停放的车辆位于视觉中心，四周松树高低错落、树冠层叠。
- **2.2.2** 营地元素共 **12 组**，全部要实现：①两树之间的吊床、②篝火堆与环形原木凳、③木质营位平台与林间木阶步道、④山涧小溪与跨溪小木桥、⑤指路木牌、⑥树干上的鸟屋与防熊食物储藏箱、⑦苔藓蕨类与蘑菇丛、⑧垒起的柴堆、⑨晾晒的毛巾、⑩溪边的打水桶与水瓢、⑪远处层叠山脊与山腰云带、⑫林间空隙洒下的斑驳光斑。
- **2.2.3** 色彩基调：森林绿与晨雾青白，光斑与雾气**随时间变化**；构图强调"**林间静谧**"，像日本动画里夏日山林露营的一幕。

### 2.3 末日避难所营地

- **2.3.1** 地形与构图：废土上一处**被加固的营地**，车辆停在硬化地面的视觉中心，四周被**工事与围墙半包围**。
- **2.3.2** 营地元素共 **13 组**，全部要实现：①混凝土掩体与厚重的防爆门、②铁架瞭望塔与探照灯、③沙袋工事、④锈蚀集装箱与波纹铁皮围墙、⑤缠绕的铁丝网、⑥废旧汽车残骸与轮胎堆、⑦油桶与手写警示牌、⑧净水装置与冒着蒸汽的发电机、⑨拼装的太阳能板阵列、⑩旋转的雷达天线、⑪火堆上架着的油桶改造烧烤架、⑫晾衣绳上晾着的工装、⑬远处断裂的高架桥与荒废城市剪影。
- **2.3.3** 色彩基调：锈红、沙黄与混凝土灰，点缀火光与冷色荧光；构图强调"**废土据点**"，像日本动画里末世旅人的中转补给站，**依然是干净画风的治愈系末世**（呼应一·5 的禁令）。

### 2.4 高速路服务区

- **2.4.1** 地形与构图：服务区一角**带划线车位的停车区**，车辆停在视觉中心的**房车专用大车位**上。
- **2.4.2** 营地元素共 **12 组**，全部要实现：①加油站雨棚与加油机、②便利店与发光招牌、③门口的自动售货机（**货道排列可见**）、④电动车充电桩、⑤餐饮区明亮的大玻璃窗、⑥遮阳连廊与公共步道、⑦行道树与绿化带、⑧公路主线与护栏、⑨高速路牌与出口指示牌、⑩长椅与分类垃圾桶、⑪洗手池、⑫旗杆上飘动的小旗。
- **2.4.3** 色彩基调：柏油灰 + 便利店暖光 + 行道树绿；**夜间**以招牌灯箱、售货机灯光与主线车流灯光为主角；构图强调"**旅途驿站**"，像日本动画里深夜或清晨在"道の驿"停靠补给的一幕。

### 2.5 场景扩展能力（硬性架构要求）

- **2.5.1** 场景**必须**以注册表 / 模块化方式实现。
- **2.5.2** 每个场景是**独立模块**，模块内容必须包含五部分：**地形、道具布置、场景动效、色彩基调、光照钩子**。
- **2.5.3** 场景在**场景注册表**中登记，即可被 UI 与切换逻辑识别。
- **2.5.4** 新增场景**不应修改核心渲染与切换代码**，只需新增模块并注册。

### 7.1–7.4 场景专属动效（原文七·导言 + 七·1 ～ 七·4）

- **7.0（七·导言）** 动效总原则：保持"**静止但活着**"的节奏——整体像静止而精致的三维微缩世界，但带有恰到好处的细微动态。
- **7.1（七·1）海崖动效 7 项**：①串灯轻微闪烁、②天幕布料随风轻摆、③海面波光流动、④远处灯塔光束缓慢旋转、⑤海鸟偶尔掠过、⑥车内小夜灯呼吸明暗、⑦野餐垫上的纸巾被风轻掀。
- **7.2（七·2）山间松林动效 7 项**：①松针随风轻摆、②林间光斑摇曳、③溪水流光与落叶漂流、④松鼠偶尔窜过枝头、⑤吊床轻晃、⑥篝火火焰跳动与火星升起、⑦晨雾缓慢流动。
- **7.3（七·3）末日避难所动效 7 项**：①探照灯光束缓慢扫动、②警示红灯旋转、③天线指示灯闪烁、④发电机排出蒸汽、⑤火堆火星上升、⑥晾衣绳衣物飘动、⑦微尘在光柱中飘浮。
- **7.4（七·4）高速路服务区动效 5 项**：①公路主线车流灯光流动、②便利店招牌灯箱循环微闪、③售货机灯带常亮、④雨棚下小旗飘动、⑤行道树叶片轻摆。
- **跨域备注**：原文七·5（通用系统：天气粒子雨 / 雪、灯光呼吸统一节奏、布料类元素统一受风力参数控制且风力随天气变化）不在本领域；但 7.1 天幕、7.2 吊床、7.3 晾衣绳衣物、7.4 小旗均属布料类动效，实现时必须与公共风力参数系统衔接（详见负责通用系统的领域清单）。

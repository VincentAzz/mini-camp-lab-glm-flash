### 1.2 机制总览（三层数据流，照架构 §3.4/§3.5/§5.2）

```
TimePreset(纯数据) ──┐                          WeatherPreset(纯数据) ──┐
  lighting: GlobalLightParams     │            lightMod × particles × material │
  channels: 6 语义通道            │            windMul                        │
  transitionMs: 1500 (D5)         │            transitionMs: 1500 (D5)        │
                                  ▼                                           ▼
        TimeLightSystem（写灯光 rig/天空/雾基准，产出 SceneLightState）
                                  │
        WeatherMaterialSystem（材质 7 分量插值 → 共享 uniform）
                                  │
        AtmosphereSystem（雾单通道合成 D6：fog=(scene.baseFog+time.fogBase)×weather.fogMul）
                                  │
   ┌──────────────────────────────┼───────────────────────────────┐
   ▼                              ▼                               ▼
scene.lightHooks          vehicle.interiorLightHooks      公共执行系统
.applyLighting(state,b)   .applyInteriorLight(p,e,b)      Wind/Particles/Breath/Scheduler
（连续量随 b 插值；        （车内灯功率/强调，D2 链）        （节奏全部取自 RhythmClock）
 离散量 b≥0.5 切换）
```

要点：**时间档与天气档都只是数据**；"怎么变"由三个系统执行，"变成什么"由各场景 `lightHooks` 解释。四档时间 × 五档天气不产生任何 if 组合分支，全部是数值合成（§3.7）。

## 2. 时间系统实现方案（原文第四节）

### 2.1 实现机制：光照预设 + 装饰物状态切换【四-总则 L81、四-5 L87】

四-总则要求"灯光、天空、阴影与装饰物状态都要发生对应变化，不允许只换色调不换内容"。落实为**两类状态、两条更新路径**：

1. **连续量**（灯光颜色/强度、天空渐变端点、雾、灯点功率、帆船位置、探照灯扫速……）：随过渡 blend∈[0,1] 全程逐帧插值（§2.6）。
2. **离散量**（早餐餐具出现/收起、送货小车出现/消失、篝火炭块余烬色/熄灭色）：`applyLighting(state, blend)` 内以 `state.time` 为 key 维护 `lastDiscreteKey`，当 blend 首次 ≥0.5 时切换目标态，新出现的物体做 0.2s 透明度短淡入（架构 D5 已定）。切换用 `material.opacity + transparent` 渐变，不用 scale 弹跳（保持"定格陈列感"，七·导言 L110）。

每场景必须实现的四档差异最低集合（自检口径，对应四-总则）：①天空渐变端点不同（§2.2 表）；②主光方向/色/影不同；③语义通道值不同（§2.3 表）；④至少 1 项离散装饰物状态不同（§2.5 各场景表"离散"列）。四项齐备才允许勾 TASKS。

### 2.3 语义通道四档定值【四-1/2/3/4 → `TimePreset.channels`】

| 通道 | dawn | day | dusk | night | 消费方（谁读它） |
|---|---|---|---|---|---|
| `lampPower` 营地/装饰灯具 | 0.15 | 0 | 1.0 | 1.0 | 各场景 lamps（§4.4 总表） |
| `emberPower` 篝火/火堆 | 0.5 | 0 | 1.0 | 1.0 | 篝火火焰/余烬/火星/火光点光（B8） |
| `smokePower` 炊烟/蒸汽 | 0.25 | 1.0 | 0.35 | 0.15 | steam 发射器 rate 加权（§4.3） |
| `shopPower` 商业照明（D8） | 0.35 | 1.0 | 0.65 | 1.0 | 灯箱/售货机/加油棚灯/城市窗灯 |
| `interiorPower` 车内灯 | 0.2 | 0 | 0.85 | 1.0 | `applyInteriorLight()`（D2） |
| `interiorEmphasis` 车内暖光强调 | 0.2 | 0 | 0.7 | 1.0 | 同上（四-4"车内暖光更突出"） |

派生量（TimeLightSystem 计算，非预设字段）：`SceneLightState.interiorGlow = interiorPower`，供场景在营位地面铺一块暖色窗光贴花（§2.5.1 海崖冷暖对比）。

- 四-2"灯具全部熄灭"（L84）按架构 D8 解释为 `lampPower=0`（营地/装饰灯具）；商业照明走 `shopPower`，清晨 0.35"刚开灯"→白天 1.0"营业亮"→黄昏 0.65"初亮"→夜间 1.0"主角"，与七-4 不冲突（回应 03 存疑 2）。
- `lampPower=0.15`（清晨）配合 breath 参数可表达"将熄未熄"（§2.4-1）。

### 2.4 通用装饰物状态切换清单（8 项）【四-1 L83、四-2 L84、四-4 L86】

以下为**全场景通用**的装饰物状态（逐场景落位见 §2.5）。每项给出：几何体 / 材质与参数思路 / 切换方式。

**① 营地灯"将熄未熄"【四-1】**
- 几何：灯 = 立杆 CylinderGeometry(r0.012, r0.016, h0.32) + 灯罩截锥 ConeGeometry(r0.055, h0.09, 12, 1, true) + 顶盖小球；位于 `named.campLamp`。
- 材质：灯罩 toon 半透明（opacity 0.85）+ 内芯 emissive 小球；注册为 `LampHandle{ mode:'breath', params:{ period:1.5, depth:0.55, phase:rng } }`，基准功率 = `lampPower`。
- 清晨表现：功率 0.15 × depth 0.55 的 1.5s 快呼吸 → 亮度在 0.07~0.23 间不规则起伏，即"将熄未熄"；其余档 breath 退化为 steady（depth×0.2）。

**② 篝火余烬【四-1】**
- 几何：炭堆 = 4~6 个 IcosahedronGeometry(r 0.05~0.09, detail 0) 随机摆放，下垫环形石圈（12 个 SphereGeometry 半埋）；位于 `named.campfire`。
- 材质：炭块 toon，emissive 色 `#FF5A20`，`emissiveIntensity = emberPower × (0.8 + 0.2×noise(t×1.3))`（CPU 每帧写 uniform）；emberPower=0 时 emissive 关闭、albedo 变暗炭灰 `#2A2A2A`。
- 光：篝火点光（全局 ≤2 点光预算之一，架构 §7-5）intensity = emberPower×0.6，色 `#FF7A30`，半径 1.2m；余烬态配 1 个 additive 红光 halo sprite（scale 0.3m）。
- 火星：`EmitterSpec{ kind:'spark', rate: 6×emberPower /s }`（§4.3 参数）。

**③ 早餐餐具【四-1】**（摆位拍板 B1，回应 03 存疑 1）
- 几何（`geom/parts/tableware.ts`，全场景共享一套）：盘 = LatheGeometry 8 段母线（r0.09 浅盘）；杯 = LatheGeometry 直筒杯 + TorusGeometry(r0.024, tube0.005) 杯把；壶 = LatheGeometry 鼓形 + 圆柱嘴 + 环形把。一次建模，TextureCache 引用计数共享。
- 材质：陶瓷白 toon `#F5F1E8`（描边开）；壶身可选场景强调色带（Canvas 横条纹 32×32）。
- 摆位：海崖=折叠桌面（主展示：盘×2+杯×2+壶×1）；松林=篝火旁原木凳面（杯×1+盘×1）；避难所=油桶烤架旁板条箱面（盘×1+杯×1）；服务区=长椅中段（杯×1+纸盒 1）。
- 切换：仅 dawn 出现；blend≥0.5 时组透明度 0→1（0.2s），离开 dawn 反向淡出后 `visible=false`。

**④ 晾晒物露水感高光【四-1】**
- 机制：共享 uniform `uDew`（dawn=1，其余 0，随过渡插值）。三类消费：
  1. 布料/天幕/棚顶（clothTop/roofTop 表面）：toon shader 追加顶部镜面窄带高光（spec power 64、强度 0.5×uDew×normal.y）；
  2. 草坪/苔藓地面：预撒 sparkle 精灵 40~60 个（InstancedMesh 平面 0.02m，`tex/sparkleStar` 十字星 Canvas 贴图，additive），scale = 0.02×(0.6+0.4×sin(t×2.7+phase))，opacity = uDew×0.8，位置由场景 rng 撒在草坪区；
  3. 晾晒毛巾/工装本体（ClothHandle 材质）同 1。
- 白天 uDew→0，高光与精灵同步淡出（露水"晒干"）。

**⑤ 灯具全熄 + 投影清晰【四-2】**
- `lampPower=0`：全部 `LampHandle` emissiveIntensity=0、halo sprite opacity=0（<0.02 直接 `visible=false` 省 draw call）。
- 投影清晰：day 阴影 radius 1.6（§2.2）+ 天幕/遮阳棚 cloth mesh `castShadow=true`；因布料顶点在 shader 中随风摆，需同步给 `mesh.customDepthMaterial` 挂同一顶点位移函数，保证影子与可见摆动一致（§4.2 代码）。

**⑥ 炊烟/蒸汽"白天活动"细节【四-2】**
- 发射源：海崖烧烤炉烟囱口、松林篝火（白天熄火冒烟）、避难所发电机排气（常转 + 白天增密，B6）、服务区餐饮区排气口。
- `EmitterSpec{ kind:'steam', rate: 2.2×smokePower + 0.4 /s }`：白天 smokePower=1 时显著，清晨 0.25 微量，夜间 0.15 近无（§4.3 参数）。

**⑦ 黄昏"点灯时刻"【四-3】**
- 通用面：`lampPower` 0→1、`interiorPower`→0.85、`shopPower`→0.65，全部随 1500ms 过渡上升；halo 光晕随功率同步长大（§4.4）。各场景专属（串灯/灯塔/招牌/探照灯）见 §2.5。

**⑧ 夜间"全灯点亮 + 月光星空"【四-4】**
- 8 项原文枚举灯的点亮落点：串灯（海崖 lamps）、营地灯（海崖）、车内灯（车型 interior，power 1.0 + emphasis 1.0）、灯塔光束（海崖 beam）、便利店灯箱（服务区 shopPower）、售货机灯带（服务区，常亮下限 0.7，B5）、探照灯（避难所 beam）、警示红灯（避难所 rotate）——汇总注册表见 §4.4。
- 光晕：每灯 1 个 additive halo sprite（`tex/haloRadial`），scale = 灯径×(1.6~2.2)，opacity = 0.35×lampPower×(1+0.5×glowBoost)——夜间+浓雾时最盛（§3.4）。
- 星空：900 主星 Points（`tex/starDot` 圆点，sizeAttenuation=false，1.5~2.5px）+ 银河带 300 暗星；闪烁 alpha = 0.7+0.3×sin(t×0.9+phase)。月面：128² Canvas（底 `#E8ECF4` + 5 个 alpha0.12 陨坑圆 + 边缘暗晕），billboard r0.9 于天穹，外挂月晕 halo ×2.4。

### 2.6 平滑光照过渡实现（1500ms）【四-5 L87、六-5 L106】

原文"1~2 秒"区间由架构 D5 定值 **1500ms**（时间与天气同标准），常量集中在 `core/transition.ts`。实现方式：

- **单 pass 参数插值**（非双场景混合渲染，架构 §5.3 已定）：`TransitionController` 持有 from/to 两组 `GlobalLightParams + channels`，每帧 `b = smoothstep(t/1500)` 输出插值结果——光照、天空、雾、通道一次算完，无重装配。
- **颜色插值在线性空间**：预设载入时 `convertSRGBToLinear()`，lerp 后再交给渲染层，避免 sRGB 直接 lerp 造成的中间调发灰。
- **主光方向插值用方向向量 slerp**（仰角 9°→62° 跨度大，欧拉 lerp 会扫过奇怪路径）；阴影只 lerp radius/bias，不重建 shadow map 链（架构 §7-6）。
- **离散量中点切换**：blend≥0.5 首帧切目标态 + 0.2s 短淡入（§2.1）。
- **中途改档不跳变**：`start()` 先把当前帧的插值中间态快照为新的 from，再指向新 to——连续拨动时间按钮也平滑。

```ts
// core/transition.ts（示意，接口与架构 §5.3 一致）
start(to: TimePreset) {
  this.from = this.snapshotCurrent();   // 快照当前插值中间态
  this.to = to; this.t = 0;
}
update(dt: number) {
  this.t = Math.min(this.t + dt, MS);
  const b = smoothstep(this.t / MS);                    // easeInOut
  const g = lerpLightParams(this.from, this.to, b);     // 颜色线性空间、方向 slerp
  TimeLight.apply(g);                                   // 灯 rig / 天空 / 雾基准
  const ch = lerpChannels(this.from.ch, this.to.ch, b);
  const st = buildSceneLightState(g, ch);
  scene.lightHooks.applyLighting(st, b);                // 连续量插值 + 离散量(b≥0.5)
  vehicle.interiorLightHooks.applyInteriorLight(ch.interiorPower, ch.interiorEmphasis, b);
}
```

- 首帧不播过渡：装配完成后 `applyLighting(blend=1)` 直接呈现默认组合「海崖 · C型 · 黄昏 · 晴朗」（架构 §5.1，L3）。
- 相机全程不动（六-5）。切换期间每帧成本 = 参数 lerp + 若干 uniform 写入，无 GC 压力。

### 3.2 多云【五-2 L94：云量增加 / 光照柔化 / 云影移动 / 风力略增】

- **云量增加**：`render/sky.ts` 云条带 opacity 由 0.15→0.55（cloudiness uniform），天空渐变两端色向 `#9AA6B8` lerp 25%（"光照柔化"的天空侧）。
- **光照柔化**：`intensityMul 0.82 + ambientMul 1.12`（明暗对比压小）+ 阴影 radius 由时间档值放大至 max(radius, 3.2)（影子发虚）。
- **云影在地面缓慢移动**：共享 512² Canvas fbm 噪声贴图（`tex/cloudFbm512`，平铺 2×2 覆盖底座），所有 `WeatherSurface{kind:'ground'}` 与大型地形材质的 shader 追加：`light ×= 1 − 0.28×cloudShadow×fbm(worldXZ×0.08 + windDir×t×0.008)`。uv 沿当前风向滚动 → 云影缓移；CPU 每帧只写一个 offset uniform（架构 §7-7 shader 化要求）。
- **风力略增**：`windMul 1.3` → WindSystem 目标风速上浮 30%（§4.2），全布料可见摆幅增大。

### 3.3 小雨【五-3 L95：雨丝 / 湿地反光 / 水洼涟漪 / 布料下凹 / 屋檐滴水 / 夜间彩色反光】

**雨丝粒子**（`EmitterSpec{kind:'rain'}`，参数 §4.3）
- 几何：InstancedBufferGeometry 细长 quad（0.008×0.14m），shader 沿速度方向拉伸 + 面向相机 billboard；材质 additive `#A8C8E8` op 0.35。
- 运动：v=4.5m/s 垂直下落 + 风向漂移 0.3×wind；发射区 = 底座上空 3.4×3.4×2.4m 盒；顶部 15% 淡入、触地 10% 淡出。密度 450/s（存活 ≈240，预算 §6）。

**地面湿润反光**（`wetness` → ground 类 WeatherSurface 共享 shader 分支）
1. albedo ×0.82（湿深）；2. 追加"假环境反射"：按视线方向 fresnel 混入当前天空 horizon 色（湿地面像镜）；3. 高光带增强（spec ×(1+3×wetness)）。三者均单 uniform 开关，逐帧随过渡插值。

**夜间灯光拉出彩色反光**【五-3 末句】：**镜面反光条**——对每盏近地强灯（灯箱/售货机/加油棚灯/路灯/营地灯，场景注册时标 `castReflection:true`，每场景 ≤6 盏）在其正下方地面预置一片竖长贴花 quad（0.25×0.5m），**每帧旋转到朝向相机方位角**（标准假反光手法），颜色 = 灯色、additive、`opacity = wetness × lampPower(或shopPower) × 0.5`。op<0.02 时 `visible=false`。雨天夜间：暖橙灯箱在湿地拉出橙色光带——即原文效果。

**水洼涟漪**：每场景 buildProps 预置 5~9 个水洼锚点（rng 取低洼位，半径 0.15~0.35m 贴花 quad，y+0.002 polygonOffset）；shader：`alpha = puddle×falloff(r)`，内部 `ripple = sin(dist×90 − t×3.2)×0.5+0.5` 调制亮度；水洼面色 = 当前天空 horizon 色（自动随时间/天气变色，夜间近灯处再 mix 灯色 30%——灯倒影进水洼）。

**布料积水下凹**（`clothSag` → ClothHandle 顶点位移，M1）
```glsl
// cloth 顶点着色器追加（在风力位移之后）
pos.y -= uSagAmp * uClothSag * sagCurve(uv);      // sagCurve: 边缘0→中心1的抛物线
pos.x += uSagAmp * uClothSag * 0.3 * sagCurve(uv) * uWindDir.x; // 迎风侧偏移，形态不呆板
```
每块布 `sagAmp` 定值：天幕 0.06m、A/B 型遮阳棚 0.05m、拖挂遮阳棚 0.045m（§4.2 表）。下凹最低点即滴水点。

**屋檐滴水**：`EmitterSpec{kind:'drip'}` 两种来源：①真实檐口——服务区便利店/加油站雨棚边缘 2~4 个锚点、避难所掩体檐口；②布檐最低点——各场景天幕/遮阳棚的 `dripAnchors`（M1 注册时算好）。水珠 = 0.015m 拉伸小球/quad，3m/s 下落；触地生成 0.25s 扩张环 sprite（复用水洼涟漪视觉）。

**雨对全局的次要修正**：sky 色向灰 `#8A94A8` lerp 35%（并入 cloudiness 通道）；海面/溪流波光强度 ×0.9；`windMul 1.45`。

### 3.4 浓雾【五-4 L96：远景逐层雾化 / 灯光扩散光晕 / 景深压缩 / 静谧朦胧】

- **雾主通道（D6 单通道合成）**：`fog01 = clamp((scene.baseFog + time.fogBase) × fogMul, 0, 1)`；映射到 `THREE.FogExp2.density = 0.015 + fog01^1.6 × 0.075`（实现期标定）。雾色 = mix(当前时间天空 horizon 色，`#8A94A8`，0.5×cloudiness)。
- **远景逐层雾化**：D1 的后缘剪影板（帆船灯塔/山脊云带/高架桥城市）按层深 far→near 各持有 layerFade uniform，AtmosphereSystem 按 `layerAlpha = 1 − clamp(fog01×layerDepth×1.6, 0, 0.95)` 逐层压透明——远层先没入雾中，形成"逐层"退隐而非一刀切。
- **灯光扩散光晕**：`glowBoost 0.8` → halo sprite scale ×(1+0.8×glow)、opacity ×(1+0.5×glow)（§2.4-⑧ 公式）；光束锥 shader alpha ×(1+0.6×glow)——浓雾夜里灯塔光束体积感最强。
- **景深层次被压缩**：①FogExp2 密度上升（中远景自然压平）；②天空 zenith/horizon 向雾色 lerp 35%（背景对比压缩）；③toon 色阶 ramp 对比远物 ×0.7（可选，按 layerFade 同一 uniform 驱动）；④描边壳透明度 ×(1−0.3×fog01)（远物描边变淡，轮廓"融进"雾里）。
- **静谧**：`windMul 0.85`、微尘/落叶类场景粒子 rate ×0.5、海面波光 ×0.85。

### 3.5 降雪【五-5 L97：雪花粒子 / 5 类积雪 / 地面薄雪 / 划线隐现】

**雪花粒子**（`EmitterSpec{kind:'snow'}`，§4.3）：InstancedMesh quad 0.02~0.045m，70% 软圆点 + 30% 六瓣雪晶（`tex/snowCrystal`）；下落 0.55m/s（"缓慢飘落"）+ 每片相位横向摆 ±0.08m + 风漂移；密度 180/s（存活 ≈800，§6 预算内）；op 0.85，顶/底淡入淡出。

**积雪覆层**（`snowCover` 0→1 随 1500ms 过渡）按表面类型四种做法：

| 部位（原文枚举） | WeatherSurface kind | 做法 |
|---|---|---|
| 屋顶（便利店/雨棚/掩体顶） | `roofTop` | **雪壳覆层**：buildProps 时预建顶面克隆网格（法线外推 0.012m 预留），SnowMaterial（白 toon `#EDF2F9` + 微蓝暗部 ramp，noOutline）；`visible = snowCover>0.01`，顶点沿法线外推 0.012×snowCover、opacity=min(1, 2×snowCover) |
| 天幕 / 遮阳棚顶 | `clothTop` | 雪壳同上但挂在 ClothHandle 之下，**继承布料风摆与 sag 位移**（同一 shader 链），雪随布动 |
| 树枝（松林树冠） | （材质级） | canopy 材质加 `snowable:true`：`color = mix(base, #EDF2F9, smoothstep(0.25,0.7,normal.y)×snowCover)`——顶面朝上处积雪、侧面不留，风格化且零额外网格 |

### 3.6 天气切换过渡【五-6 前半 L98：粒子与材质平滑过渡】

- 时长同为 1500ms（D5）；`WeatherMaterialSystem` 对 7 个 material 分量逐帧插值写共享 uniform（与 §2.6 同一套 smoothstep 机制，两维各自独立过渡、可同时进行——时间过渡插基准值，天气过渡插修正系数，每帧相乘合成，§3.7）。
- **粒子淡出淡入**：旧发射器 rate 0.5s 内降到 0，存量粒子按自身生命周期自然消亡，且整组 opacity 随 blend 反向淡出；新发射器 rate 0.5s 内升满、组 opacity 随 blend 淡入。雨↔雪↔无 的切换在 1.5s 内无跳变（雨 life 0.53s 自然死光；雪 life 4.4s，靠组 opacity 淡出兜底；过渡期双组并存，存活峰值 ×2 仍在预算内 §6）。
- **风力平滑趋近**：`wind.current += (windMul×base − current) × (1 − exp(−dt/0.6))`，布料摆幅无级变速。
- 云影/积雪/湿润/下凹全部是 uniform 插值，天然平滑。

### 3.7 天气 × 时间综合光照合成规则【五-6 后半 L98】

**公式**（TimeLightSystem 每帧执行，先时间后天气，与两维过渡 blend 无关地可组合）：

```
intensity = time.lighting.sunIntensity × weather.lightMod.intensityMul
ambient   = time.lighting.hemi        × weather.lightMod.ambientMul
glowBoost = weather.lightMod.glowBoost                       （叠加给所有 halo/光束）
fog01     = clamp((scene.baseFog + time.lighting.fogBase) × weather.material.fogMul, 0, 1)   // D6
sky       = time.sky 色向天气灰调 lerp(0.5×cloudiness/雨)
particles = weather.particles ＋ scene emitters（smokePower 等通道调制 rate）
```

主光**颜色/方向不乘天气**（雨雾天太阳变暗不变色，符合三渲二直觉；浓雾的"变灰"走雾色与天空压缩）。原文示例「夜间浓雾 = 更暗 + 更强光晕」即：`0.38×0.55=0.21 更暗` ✓ ＋ `glowBoost 0.8` ✓。

### 4.2 风力与布料统一系统【七-5 L116：布料统一受风力参数控制、风力随天气变化】

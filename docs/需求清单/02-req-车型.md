## 一、逐条要点

### 三·总则（原文第 46、48 行）

- 【3·总则-1】车型系统首发 5 种车型（3.1–3.5），架构上可继续扩展。（L46）
- 【3·总则-2】车型与场景解耦：任何车型可出现在任何场景的中央营位。（L48）
- 【3·总则-3】所有车型都保留两个核心特征：「外拓展机构已展开」与「内部可透过车窗 / 帐帘清楚看到」。（L48）
- 【3·总则-4】不同车型的展开方式、涂装与内饰风格必须有明显差异。（L48）
- 【3·总则-5】细节量比较基准：每款车型细节量不得少于 C 型房车（3.1 所列内/外部元素清单即为基准线）。（L48）
- 【3·总则-6】不同车型进入不同场景时允许轻微适配，适配项举例为接地高度、朝向、末世场景下的蒙尘涂装等，且明确「不强制」。（L48）

### 3.1 C型房车（默认车型）（L50–53）

- 【3.1-1】C型房车是默认车型（默认启动组合「海崖 · C型房车 · 黄昏 · 晴朗」亦见原文 L3）。（L50）
- 【3.1-2·外部】升顶展开。（L52）
- 【3.1-3·外部】侧拓展舱滑出。（L52）
- 【3.1-4·外部】经典 C 型驾驶舱凸头造型。（L52）
- 【3.1-5·内部·透视途径】透过升顶帐帘与大面积车窗清楚看到内部。（L53）
- 【3.1-6·内部】驾驶舱大屏与仪表。（L53）
- 【3.1-7·内部】卡座餐桌。（L53）
- 【3.1-8·内部】厨房区的水槽与灶台。（L53）
- 【3.1-9·内部】冰箱。（L53）
- 【3.1-10·内部】吊柜。（L53）
- 【3.1-11·内部】床铺与温暖的小夜灯（小夜灯同时是 3.6「内饰灯光钩子」的 C 型落点，对应动效见七.1「车内小夜灯呼吸明暗」）。（L53）
- 【3.1-12·内部】侧拓展舱内的沙发与书架。（L53）
- 【3.1-13·内饰氛围】车内要显得明亮、温暖、真实、充实，与室外渐暗的蓝调时刻海天形成鲜明冷暖对比（黄昏时段最明显），营造温馨紧凑的旅居感。（L53）

### 3.2 A型大巴式房车（L55–58）

- 【3.2-1·外部】方正的大巴式车身。（L57）
- 【3.2-2·外部】大面积前挡风与贯通侧窗。（L57）
- 【3.2-3·外部】车顶空调外机与卫星锅。（L57）
- 【3.2-4·外部】侧裙储物舱门。（L57）
- 【3.2-5·外部】展开的侧遮阳棚与电动踏步（遮阳棚为「展开」状态，呼应 3·总则-3）。（L57）
- 【3.2-6·外部】车尾自行车架与折叠自行车。（L57）
- 【3.2-7·内部】环形豪华沙发卡座。（L58）
- 【3.2-8·内部】中岛厨房，含双开门冰箱、水槽、嵌入式灶台与烤箱（四件子细节）。（L58）
- 【3.2-9·内部】通顶吊柜与暖色灯带（暖色灯带为该车的内饰灯光落点）。（L58）
- 【3.2-10·内部】木纹地板。（L58）
- 【3.2-11·内部】半隔断的独立卧室与双人床。（L58）
- 【3.2-12·内部】小卫浴间，可见洗手盆与淋浴隔断。（L58）
- 【3.2-13·内饰风格】整体是「移动小公寓」式的暖木色豪华感，与 C 型的紧凑温馨形成对比。（L58）

### 3.3 拖挂式房车 + 牵引皮卡（L60–63）

- 【3.3-1·外部】一辆全尺寸皮卡，货斗里载着行李箱、备用油桶与柴火（三件子细节）。（L62）
- 【3.3-2·外部】由该皮卡牵引一辆流线型白色拖挂房车（本车型为「皮卡+拖挂」双主体组合）。（L62）
- 【3.3-3·外部】到位后拖挂支撑腿放下。（L62）
- 【3.3-4·外部】到位后拖挂遮阳棚展开。（L62）
- 【3.3-5·外部】拖挂前部的燃气瓶与备胎可见。（L62）
- 【3.3-6·内部·透视途径】拖挂车厢两侧大窗可透视。（L63）
- 【3.3-7·内部·拖挂】尾部横置双人床与舷窗。（L63）
- 【3.3-8·内部·拖挂】一侧紧凑厨房与吊柜。（L63）
- 【3.3-9·内部·拖挂】对坐卡座与可升降小桌板。（L63）
- 【3.3-10·内部·拖挂】小卫生间隔断。（L63）
- 【3.3-11·内部·皮卡】皮卡双排驾驶舱内可见仪表盘、中控屏与后座的睡袋行李（三件子细节）。（L63）
- 【3.3-12·内饰风格】整体是「车队式」的旅居感。（L63）

### 3.4 B型露营面包车（vanlife）（L65–68）

- 【3.4-1·外部】圆润紧凑的复古双色面包车。（L67）
- 【3.4-2·外部】车顶行李架与捆着的冲浪板。（L67）
- 【3.4-3·外部】侧边遮阳棚。（L67）
- 【3.4-4·外部】后掀式尾门与纱帘。（L67）
- 【3.4-5·外部】车身侧面的手绘小贴纸。（L67）
- 【3.4-6·内部·透视途径】大侧窗与掀顶帐帘透视。（L68）
- 【3.4-7·内部】对坐小卡座与翻折小桌（可变床结构做成半展开状态展示——「半展开」为原文明确指定状态）。（L68）
- 【3.4-8·内部】迷你厨房，含单孔灶、小水槽、迷你冰箱（三件子细节）。（L68）
- 【3.4-9·内部】车内串灯（该车的内饰灯光落点）。（L68）
- 【3.4-10·内部】挂毯与小盆栽。（L68）
- 【3.4-11·内部】手冲咖啡具与散落的书。（L68）
- 【3.4-12·内饰风格】装饰风格慵懒随性，是「自由职业者在路上」的氛围。（L68）

### 3.5 越野皮卡 + 车顶帐篷（overlanding）（L70–73）

- 【3.5-1·外部】升高底盘与全地形胎的硬派越野皮卡。（L72）
- 【3.5-2·外部】车顶行李架上的折叠帐篷：已展开、带登车梯与帐篷边 LED 灯串（「已展开」与灯串均为明确要求；LED 灯串在车顶帐篷外侧）。（L72）
- 【3.5-3·外部】侧边遮阳幕。（L72）
- 【3.5-4·外部】货斗里的油桶 / 水箱 / 工具箱 / 折叠桌板（四件子细节）。（L72）
- 【3.5-5·外部】车侧爬梯与车顶探照灯。（L72）
- 【3.5-6·内部·透视途径】双排车窗透视。（L73）
- 【3.5-7·内部】驾驶舱全液晶仪表与中控大屏。（L73）

### 3.6 车型扩展能力（硬性架构要求）（L75–77）

- 【3.6-1】与场景（2.5）同理：车型也做成注册表 / 模块化。（L77）
- 【3.6-2】每个车型模块必须声明四项内容：外部模型、展开机构、透视内饰、内饰灯光钩子。（L77）
- 【3.6-3】新增车型 = 新增模块并注册，不修改核心逻辑。（L77）
- 【3.6-4·旁证】原文八.4（L123）要求「场景 / 车型 / 时间 / 天气做成四套互相独立的注册表与数据模块（见 2.5、3.6）」，与 3.6 相互印证。

## 二、硬性约束（每条一句话，带原文小节号）

1. 【三·总则 L46】首发车型共 5 种（3.1–3.5），且架构上必须可继续扩展。
2. 【三·总则 L48】车型与场景完全解耦，任何车型可出现在任何场景的中央营位。
3. 【三·总则 L48】所有车型必须保留两个核心特征：外拓展机构已展开、内部可透过车窗 / 帐帘清楚看到。
4. 【三·总则 L48】不同车型的展开方式、涂装与内饰风格必须有明显差异。
5. 【三·总则 L48】3.2–3.5 每款车型的细节量不得少于 C 型房车（以 3.1 所列内外元素清单为比较基准）。
6. 【三·总则 L48】车型跨场景仅允许轻微适配（接地高度、朝向、末世蒙尘涂装等），且该类适配不强制。
7. 【3.1 L50】C型房车为默认车型（默认组合「海崖 · C型房车 · 黄昏 · 晴朗」）。
8. 【3.1 L52】C型外部必须含：升顶展开、侧拓展舱滑出、经典 C 型驾驶舱凸头造型。
9. 【3.1 L53】C型内部（透过升顶帐帘与大面积车窗可见）必须含：驾驶舱大屏与仪表、卡座餐桌、厨房区水槽与灶台、冰箱、吊柜、床铺与温暖的小夜灯、侧拓展舱内沙发与书架。
10. 【3.1 L53】C型内饰必须呈现明亮、温暖、真实、充实的观感，与黄昏蓝调时刻室外形成鲜明冷暖对比，营造温馨紧凑的旅居感。
11. 【3.2 L57】A型外部必须含：方正大巴式车身、大面积前挡风与贯通侧窗、车顶空调外机与卫星锅、侧裙储物舱门、展开的侧遮阳棚与电动踏步、车尾自行车架与折叠自行车。
12. 【3.2 L58】A型内部必须含：环形豪华沙发卡座、中岛厨房（双开门冰箱、水槽、嵌入式灶台与烤箱）、通顶吊柜与暖色灯带、木纹地板、半隔断独立卧室与双人床、小卫浴间（可见洗手盆与淋浴隔断）。
13. 【3.2 L58】A型内饰风格必须是「移动小公寓」式暖木色豪华感，与 C 型紧凑温馨形成对比。
14. 【3.3 L62】本车型必须由一辆全尺寸皮卡（货斗载行李箱、备用油桶与柴火）牵引一辆流线型白色拖挂房车组成。
15. 【3.3 L62】拖挂车必须呈现到位停放状态：支撑腿放下、遮阳棚展开、前部燃气瓶与备胎可见。
16. 【3.3 L63】拖挂车厢两侧大窗必须可透视，内部含：尾部横置双人床与舷窗、一侧紧凑厨房与吊柜、对坐卡座与可升降小桌板、小卫生间隔断。
17. 【3.3 L63】皮卡双排驾驶舱内必须可见仪表盘、中控屏与后座的睡袋行李；整体呈现「车队式」旅居感。
18. 【3.4 L67】B型外部必须含：圆润紧凑复古双色面包车、车顶行李架与捆着的冲浪板、侧边遮阳棚、后掀式尾门与纱帘、车身侧面手绘小贴纸。
19. 【3.4 L68】B型内部（大侧窗与掀顶帐帘透视）必须含：对坐小卡座与翻折小桌（可变床结构做成半展开状态展示）、迷你厨房（单孔灶、小水槽、迷你冰箱）、车内串灯、挂毯与小盆栽、手冲咖啡具与散落的书。
20. 【3.4 L68】B型装饰风格必须慵懒随性，呈现「自由职业者在路上」的氛围。
21. 【3.5 L72】越野皮卡外部必须含：升高底盘与全地形胎、车顶行李架上已展开的折叠帐篷（带登车梯与帐篷边 LED 灯串）、侧边遮阳幕、货斗内的油桶 / 水箱 / 工具箱 / 折叠桌板、车侧爬梯与车顶探照灯。
22. 【3.5 L73】越野皮卡内部（双排车窗透视）必须含：驾驶舱全液晶仪表与中控大屏、后座改装休憩区（睡袋、摊开的地图、手持对讲机与杂物网兜）；风格硬朗但整洁，呈现「远征装备控」细节感。
23. 【3.6 L77】车型系统必须做成注册表 / 模块化架构（与场景 2.5 同理）。
24. 【3.6 L77】每个车型模块必须声明四项：外部模型、展开机构、透视内饰、内饰灯光钩子。
25. 【3.6 L77】新增车型只允许「新增模块并注册」，不得修改核心逻辑。

## 三、存疑点（原文含糊、疑似冲突或需用户拍板处）

1. 【三·总则 L48 ↔ 一.6 L12】3.5 内部清单中的「手持对讲机」：原文一.6 明确「不要人物」，则该词应理解为「手持式对讲机」这一道具类型（摆放于后座）还是字面上被某人手持？原文未明说，需确认。
2. 【3.3 L62-63 ↔ 3.6 L77】3.3 是「皮卡 + 拖挂」双主体组合：注册粒度上应作为一个车型模块（内含两子模型）还是拆成两个模块，原文未规定；皮卡与拖挂的相对摆位（牵引朝向、连接角度、是否分别视为「车辆位于视觉中心」）原文也未定义。
3. 【3.3 / 3.5 ↔ 3.6 L77 ↔ 4·夜间 L86】3.3 与 3.5 的内部清单均未列举任何车内灯光元素（对比 3.1 小夜灯、3.2 暖色灯带、3.4 车内串灯），但 3.6 要求每个车型模块声明「内饰灯光钩子」，且 4.夜间要求「车内暖光更突出」——3.3 / 3.5 的内饰灯光具体形态原文未指明，需确认是否由设计文档补充。
4. 【三·总则 L48】「细节量不得少于 C 型房车」未给出量化口径（按元素计数、建模精度还是视觉密度衡量），原文只能以 3.1 清单作定性基准，验收时如何判定「不少于」存在解释空间。
5. 【3.2 / 3.3 / 3.4 / 3.5 ↔ 五.3 L95 ↔ 七.5 L116】各车型自带的布料件（A型/拖挂/B型的遮阳棚、3.4 纱帘、3.5 遮阳幕、升顶帐帘）：五.3 提到「天幕与遮阳棚布料因积水微微下凹」，七.5 的风力统一控制清单却只列「天幕、吊床、挂毯、晾晒衣物、小旗」未列车辆遮阳棚 / 纱帘 / 帐帘——车型布料件是否纳入天气（积水下凹）与风力系统统一控制，原文未明确。
6. 【三·总则 L48】「末世场景下的蒙尘涂装」被列为「不强制」的轻微适配项：即同一路径下存在「涂装随场景切换变化」与「不变化」两种实现，原文未给出默认取向，需在设计文档阶段拍板。
7. 【3.3 L62】「到位后」一词暗示拖挂展开状态是停放后的静态结果，但原文未说明该车展开机构（支撑腿、遮阳棚）是否需要呈现动作过程或参与时间 / 天气联动（如夜间支撑腿区域灯光、雨天棚布状态）。

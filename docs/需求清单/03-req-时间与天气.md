## 一、逐条要点

### 第四节 时间系统（清晨 / 白天 / 黄昏 / 夜间）

**四-总则（L81）**
- 时间与场景解耦；每个场景都必须完整实现四种时间。
- 切换时间时，场景的**灯光、天空、阴影与装饰物状态**都要发生对应变化——**不允许只换色调不换内容**。

**四-1 清晨（L83）**
- 光照：低角度**青金色**晨光、薄雾、长投影。
- 装饰物状态（4 项）：营地灯**将熄未熄**；篝火**只剩余烬**；桌上出现**早餐餐具**；晾晒物带**露水感高光**。
- 场景专属表现（4 项）：
  - 海崖：**朝霞**与**刚刚出海的小帆船**（帆船位置状态随时间变化）。
  - 松林：**流动晨雾**与**鸟鸣般的光斑跳动**。
  - 服务区：**刚开灯的便利店**与**送货小车**。
  - 避难所：**刚换岗扫动的探照灯**。

**四-2 白天（L84）**
- 光照：明亮柔和的正午光、干净饱和的色彩、**短而清晰**的阴影。
- **灯具全部熄灭**；天幕与遮阳棚投影清晰。
- 出现**炊烟、蒸汽**等"白天活动"细节。

**四-3 黄昏（默认时间档）（L85）**
- 黄昏是**默认档**（默认启动组合「海崖 · C型房车 · 黄昏 · 晴朗」，见 L3、L151）。
- 必须保留原始设计的核心氛围：**日落金橙与海面蓝紫渐变、天边晚霞渐变、蓝调时刻、暖色车内灯光与冷色暮色海景的强烈对比**。
- 场景专属表现（4 项）：
  - 海崖：**串灯点亮**、**灯塔开始工作**。
  - 松林：变为**逆光剪影**与**金色光斑**。
  - 服务区：**招牌灯箱初亮**、**车流渐密**。
  - 避难所：**探照灯与警示灯启动**。

**四-4 夜间（L86）**
- **月光与星空主导**，环境呈**深蓝紫色**。
- **所有灯光道具点亮并带柔和光晕**，原文枚举清单（8 项）：串灯、营地灯、车内灯、灯塔光束、便利店灯箱、售货机灯带、探照灯、警示红灯。
- **车内暖光更突出**，成为深夜中的温暖焦点。

**四-5 实现要求（L87）**
- 时间实现方式固定为：**"光照预设 + 装饰物状态切换"**。
- 切换时有 **1~2 秒**的平滑光照过渡（**交叉淡入淡出**），**不生硬跳变**。

### 第五节 天气系统（晴朗 / 多云 / 小雨 / 浓雾 / 降雪）

**五-总则（L91）**
- 天气与场景、时间解耦，**任意组合均有效**（原文示例：「夜间小雨的末日避难所」「清晨浓雾的山间松林」「黄昏降雪的海崖」）。
- 天气影响三要素：**光照强度、粒子效果与材质状态**。

**五-1 晴朗（默认天气档）（L93）**
- 晴朗是**默认档**，定义为"各场景的基准表现"（即不加天气叠加，时间光照预设直接生效）。

**五-2 多云（L94）**
- 4 项表现：**云量增加**、**光照柔化**、**云影在地面缓慢移动**、**风力略增**。

**五-3 小雨（L95）**
- **雨丝粒子**。
- **地面湿润反光**与**水洼涟漪**。
- **天幕与遮阳棚布料因积水微微下凹**（布料形变）。
- **屋檐滴水**。
- **夜间灯光在湿地面上拉出彩色反光**（与时间档联动的材质表现）。

**五-4 浓雾（L96）**
- 3 项表现 + 氛围词：**远景逐层雾化**、**灯光产生扩散光晕**、**景深层次被压缩**；营造**静谧朦胧感**。

**五-5 降雪（L97）**
- **雪花粒子缓慢飘落**（慢速粒子）。
- 积雪部位（原文枚举 5 类）：**屋顶 / 天幕 / 树枝 / 护栏 / 桌椅顶部**。
- **地面覆薄雪**；特例：**服务区车位划线若隐若现**。

**五-6 实现要求（L98）**
- 天气**粒子与材质状态切换同样平滑过渡**（与四-5 时间过渡同标准）。
- **天气与时间叠加时取综合光照**（原文示例：夜间浓雾 = 更暗 + 更强光晕）。

### 第七节第 5 点 通用系统

**七-5（L116）**
- **天气粒子（雨 / 雪）、灯光呼吸统一节奏**（全局统一的时间节奏参数）。
- **布料类元素统一受风力参数控制**，原文枚举（5 类）：天幕、吊床、挂毯、晾晒衣物、小旗；**风力随天气变化**（如五-2 多云"风力略增"即作用于该参数）。

## 二、硬性约束（带原文小节号，一条不许丢）

1. 【四-总则】时间与场景解耦，每个场景必须完整实现清晨/白天/黄昏/夜间四档；切换时灯光、天空、阴影与装饰物状态都要对应变化，不允许只换色调不换内容。
2. 【四-1】清晨 = 低角度青金色晨光 + 薄雾 + 长投影；营地灯将熄未熄、篝火只剩余烬、桌上出现早餐餐具、晾晒物带露水感高光。
3. 【四-1】清晨场景专属：海崖=朝霞与刚刚出海的小帆船；松林=流动晨雾与鸟鸣般的光斑跳动；服务区=刚开灯的便利店与送货小车；避难所=刚换岗扫动的探照灯。
4. 【四-2】白天 = 明亮柔和正午光 + 干净饱和色彩 + 短而清晰阴影；灯具全部熄灭；天幕与遮阳棚投影清晰；出现炊烟、蒸汽等"白天活动"细节。
5. 【四-3】黄昏为默认时间档，必须保留原始设计核心氛围：日落金橙与海面蓝紫渐变、天边晚霞渐变、蓝调时刻、暖色车内灯光与冷色暮色海景的强烈对比。
6. 【四-3】黄昏场景专属：海崖=串灯点亮与灯塔开始工作；松林=逆光剪影与金色光斑；服务区=招牌灯箱初亮与车流渐密；避难所=探照灯与警示灯启动。
7. 【四-4】夜间 = 月光与星空主导、环境深蓝紫色；串灯、营地灯、车内灯、灯塔光束、便利店灯箱、售货机灯带、探照灯、警示红灯全部点亮并带柔和光晕；车内暖光更突出，成为深夜温暖焦点。
8. 【四-5】时间以"光照预设 + 装饰物状态切换"实现，切换时有 1~2 秒平滑光照过渡（交叉淡入淡出），不生硬跳变。
9. 【五-总则】天气与场景、时间解耦，任意组合均有效；天气影响光照强度、粒子效果与材质状态三方面。
10. 【五-1】晴朗为默认天气档 = 各场景的基准表现。
11. 【五-2】多云 = 云量增加 + 光照柔化 + 云影在地面缓慢移动 + 风力略增。
12. 【五-3】小雨 = 雨丝粒子 + 地面湿润反光与水洼涟漪 + 天幕与遮阳棚布料积水微微下凹 + 屋檐滴水；夜间灯光在湿地面上拉出彩色反光。
13. 【五-4】浓雾 = 远景逐层雾化 + 灯光产生扩散光晕 + 景深层次被压缩，营造静谧朦胧感。
14. 【五-5】降雪 = 雪花粒子缓慢飘落 + 屋顶/天幕/树枝/护栏/桌椅顶部积雪 + 地面覆薄雪（服务区车位划线若隐若现）。
15. 【五-6】天气粒子与材质状态切换同样平滑过渡；天气与时间叠加时取综合光照（如夜间浓雾 = 更暗 + 更强光晕）。
16. 【七-5】天气粒子（雨/雪）与灯光呼吸统一节奏；布料类元素（天幕、吊床、挂毯、晾晒衣物、小旗）统一受风力参数控制，风力随天气变化。

**跨节关联（非本域，但直接约束本域实现方案，提请架构设计对齐）：**
- 【八-4，L123】「时间光照预设、天气材质状态」与「风力、粒子、灯光呼吸」同属公共系统，须沉淀为可复用模块；场景/车型/时间/天气做成四套互相独立的注册表与数据模块。
- 【六-5，L106】时间与天气切换用光照与粒子的平滑过渡，且相机拖拽/缩放状态在切换前后保持连续。
- 【十一，L151】4 时间 × 5 天气参与 400 种组合巡游，每次切换都要有灯光、装饰与氛围的真实变化。

## 三、存疑点（原文含糊 / 疑似冲突，待用户拍板，勿自行脑补）

1. 【四-1】"桌上出现早餐餐具"——原文未指明是哪个场景的哪张桌：海崖有折叠桌（L21），松林（L27）、避难所（L33）、服务区（L39）均未列餐桌。该状态是作为通用装饰状态套到所有场景，还是仅适用于有桌的场景？
2. 【四-2 × 四-1 × 七-4】白天"灯具全部熄灭"（L84）与四-1 清晨服务区"刚开灯的便利店"、七-4"售货机灯带常亮"（L115）之间的关系未界定："灯具"是否包含便利店灯、售货机灯带等商业照明？若含，则清晨刚开灯、白天全熄、夜间再亮的逐时序需确认。
3. 【四-3】服务区"车流渐密"（L85）只给了方向没有基准：白天/夜间/各天气下车流密度如何取值，原文未量化。
4. 【四-5】过渡时长"1~2 秒"是一个区间，具体取值（如统一 1.5s）需拍板；且原文只说"平滑光照过渡（交叉淡入淡出）"，装饰物状态切换是同步淡入淡出还是瞬切，未明确。
5. 【四-1】松林"鸟鸣般的光斑跳动"（L83）——全文未提及任何音频系统，"鸟鸣"应理解为光斑跳动的视觉比喻，还是需要真实鸟鸣音效？
6. 【五-3 / 五-5】小雨的雨丝密度、水洼数量与规格，降雪的积雪厚度、雪花密度，原文均未量化，需实现时定档并请确认。
7. 【五-5】降雪是否影响水面类元素（海崖海面、松林溪流是否结冰/封冻）原文未提；原文只枚举了屋顶/天幕/树枝/护栏/桌椅顶部与地面薄雪，默认按枚举处理还是需扩展？
8. 【五-6 × 四-1】"天气与时间叠加取综合光照"仅给出一例（夜间浓雾 = 更暗 + 更强光晕）；其余 19 种时间×天气组合的合成规则未给出；且清晨光照自带"薄雾"（L83），与天气"浓雾"叠加时的雾浓度合成规则也需确认。
9. 【七-5】"统一节奏"未给出具体参数：灯光呼吸的周期/幅度、天气粒子的节奏基准值均需实现时定值。
10. 【四-3 × 四-1】避难所探照灯：清晨"刚换岗扫动"（L83）暗示清晨仍亮，黄昏"启动"（L85）暗示黄昏前未启动——两个表述的时序衔接（清晨亮→白天熄？）原文未明说，需确认白天探照灯是否熄灭。
